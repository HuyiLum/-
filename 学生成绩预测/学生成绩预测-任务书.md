# 学生学业成绩预测 — 任务书

## 背景

某教育科技公司收集了 1000 名高中生的学习与生活数据，涵盖**学习习惯**、**生活方式**、**家庭背景**三个维度。公司希望通过这些数据构建预测模型，在教学过程中实现：

- **早期预警**：提前识别可能挂科或成绩下滑的学生
- **个性化干预**：根据影响因素为学生制定针对性的学习建议
- **成绩预测**：基于期中表现（previous_grade）和行为数据，预估期末成绩

你作为数据分析实习生，需要完成以下任务。

---

## 数据说明

**数据集**：`学生表现与学习习惯数据集.csv`，共 1000 条记录，12 个字段。

### 字段一览

| 字段 | 说明 | 类型 | 备注 |
|------|------|------|------|
| student_id | 学生编号 | 数值 | 主键 |
| gender | 性别 | 分类 | Male / Female |
| study_time_hours | 每日学习时长（小时） | 数值 | 0.5 ~ 8.1 |
| attendance_percent | 出勤率（%） | 数值 | 54.8% ~ 100% |
| sleep_hours | 每日睡眠时长（小时） | 数值 | 3.2 ~ 10.0 |
| parental_education | 父母最高学历 | 分类 | None / High School / Bachelors / Masters / PhD（含 102 条缺失） |
| internet_access | 是否有网络接入 | 分类 | Yes / No |
| extracurricular_activities | 是否参加课外活动 | 分类 | Yes / No |
| part_time_job | 是否有兼职 | 分类 | Yes / No |
| previous_grade | 期中成绩（百分制） | 数值 | 31.3 ~ 100 |
| final_exam_score | 期末考试成绩（百分制） | 数值 | 46.8 ~ 100 |
| final_grade | 期末字母等级 | 分类 | A / B / C / D / F |

### 数据特点

- **性别均衡**：女生 510 人，男生 490 人
- **成绩分布不均衡**：B(354) > A(284) > C(261) > D(89) > F(12)，A/B 占 63.8%
- **缺失值**：parental_education 有 102 条缺失，需处理
- **偏态风险**：多数指标（出勤率、成绩）集中在高位，低分段样本少

---

## 任务要求

### 任务一：数据清洗与探索性分析（EDA）

1. 处理 `parental_education` 的 102 条缺失值（删除 / 填充 / 标记为 Unknown，说明选择的理由）
2. 对数值特征进行描述性统计，绘制分布直方图
3. 分析各分类变量（性别、父母学历、网络、课外活动、兼职）对期末成绩的影响
4. 计算各数值特征之间的相关系数矩阵，识别与 `final_exam_score` 最相关的特征
5. 输出至少 3 张有业务含义的可视化图表，并附上文字解读

### 任务二：回归预测 — 预测期末考试成绩

1. 以 `final_exam_score` 为目标变量，其余特征为输入，构建回归模型
2. 训练集 / 测试集按 **8:2** 划分（`random_state=42`）
3. **至少尝试 3 种回归算法**，建议包含：
   - 线性回归（Baseline）
   - 随机森林回归
   - XGBoost 或 LightGBM 回归
4. 使用 **MAE、RMSE、R²** 三个指标评估模型，对比并选出最优模型
5. 对最优模型进行**特征重要性分析**，指出影响成绩的前 3 大因素

### 任务三：分类预测 — 预测期末字母等级

1. 以 `final_grade` 为目标变量，构建分类模型
2. 注意 `final_grade` 是五分类且存在类别不平衡，讨论你的应对策略
3. 至少尝试 3 种分类算法（如逻辑回归、随机森林、XGBoost 等）
4. 使用 **Accuracy、加权 F1-score、混淆矩阵** 评估模型
5. 分析错误分类的样本（如把 D 预测为 C），讨论可能的业务影响

### 任务四：报告撰写

提交一份完整的分析报告（Jupyter Notebook 或 PDF），包含：
- 数据概览与清洗过程
- EDA 核心发现（每张图表配 2-3 句解读）
- 回归与分类模型的实验设计、结果对比、最优方案
- 结论：哪些因素最能预测学生成绩？对学校有何建议？
- 不足与改进方向

## 提示

- `previous_grade` 是期中成绩，和期末成绩高度相关，这是预期内的 — 重点分析**除期中成绩外**还有哪些因素能解释成绩变化
- 102 条缺失值不算少，建议对比"直接删除"和"众数填充"两种方案的效果
- 分类任务中 D 和 F 等级样本很少（101 人），如果模型在这两个等级上表现差，要说明原因
- 如果你愿意，可以尝试构造新特征（如 `study_sleep_ratio` = 学习时长 / 睡眠时长）
